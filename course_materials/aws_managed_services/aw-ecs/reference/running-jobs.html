Task lifecycle docs

Exit codes

  • 0: completed (make it mean "the plan was really written")
  • 1: application error, so check the logs
  • 137: SIGKILL, from out-of-memory or ignoring SIGTERM
  • 143: stopped by SIGTERM

re:Post

stopCode (task level)

  • TaskFailedToStart: it never ran (network, role, image)
  • EssentialContainerExited: the main container ended. Check its exit code
  • UserInitiated: someone called StopTask

Stopped-task details stay in DescribeTasks for only about 1 hour, so capture them from task state change events through EventBridge → SNS.

EventBridge Scheduler

  • Cron has 6 fields: cron(min hour day-of-month month day-of-week year), e.g. cron(0 1 * * ? *) = 01:00 daily. Use ? in one of the two day fields. docs
  • Set ScheduleExpressionTimezone so the job follows local time through daylight saving changes.
  • Templated ECS RunTask target: EcsParameters (TaskDefinitionArn required, LaunchType or CapacityProviderStrategy, NetworkConfiguration), overrides go in the input. docs
  • A third role: the Scheduler's execution role needs ecs:RunTask plus iam:PassRole for the task's roles.
  • Retry policy + DLQ cover invocation delivery, not job success.
