Logs (awslogs)

"logConfiguration": { "logDriver": "awslogs", "options": {
  "awslogs-group": "/ecs/APP", "awslogs-region": "REGION",
  "awslogs-stream-prefix": "ecs",                 // required on Fargate
  "mode": "non-blocking", "max-buffer-size": "25m" } }
  • Default mode is non-blocking since June 2025 (may drop logs when the buffer fills); blocking can freeze the app. docs
  • Execution role sends logs. Set a retention period on the log group.

Container Insights

Cluster setting containerInsights: disabled | enabled | enhanced (recommended; per-container detail). CPU, memory, disk, network per cluster/service/task; provides RunningTaskCount. Running tasks only. Extra cost. docs

ECS Exec

aws ecs update-service --cluster C --service S --enable-execute-command --force-new-deployment
aws ecs execute-command --cluster C --task ID --container NAME --interactive --command "/bin/sh"
  • Only new tasks get it. Needs: Session Manager plugin locally; task role with ssmmessages permissions; NAT or ssmmessages endpoint.
  • Runs as root; 20-min idle timeout; not with readonlyRootFilesystem; audited in CloudTrail (ExecuteCommand).
  • Break-glass tool: keep off for locked-down tasks (e.g. code sandboxes). docs

Container restart policy

"restartPolicy": { "enabled": true, "ignoredExitCodes": [0], "restartAttemptPeriod": 300 }

Restarts one container in place (essential or not), without replacing the task. Must have run restartAttemptPeriod seconds first (60–1,800, default 300). Default: restart on any exit code. docs
