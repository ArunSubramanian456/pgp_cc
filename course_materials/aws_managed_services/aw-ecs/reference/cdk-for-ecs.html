Remember

  • Task definitions hold no subnets or security groups; the service or the RunTask call does.
  • Default security groups allow all outbound: turn it off for untrusted code.
  • Grants without a key pattern default to the whole bucket.
  • CDK writes the policies; you still choose what to grant.
